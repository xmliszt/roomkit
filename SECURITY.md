# Security policy

Security fixes target the latest release and the default branch.

Use **Report a vulnerability** under the repository’s Security tab to send a private report. Include the affected version or commit, the impact, and enough information for a maintainer to reproduce the issue. Remove credentials, room photos, and personal project data from any attachments.

If private reporting is unavailable, open an issue asking for a private reporting channel. Keep the vulnerability details private while a maintainer investigates and coordinates a fix.
